# Scrisoare de dragoste — Coloana sonoră

O audiție literară pentru romanul *Scrisoare de dragoste* de Mihail Drumeș (1938): muzica numită în roman, ecouri ale epocii, referințe culturale și o hartă a locurilor.

Site: https://gcojocaru.github.io/scrisoare-de-dragoste/

Înregistrările sunt redate prin YouTube; harta folosește OpenStreetMap; identificatorii din baze de date provin din Wikidata.

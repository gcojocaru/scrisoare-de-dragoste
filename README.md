# Scrisoare de dragoste — Coloana sonoră

O audiție literară pentru romanul *Scrisoare de dragoste* de Mihail Drumeș (1938): muzica numită în roman, ecouri ale epocii, filmele, referințele culturale cu hartă și un ghid pentru clubul de lectură.

Site: https://gcojocaru.github.io/scrisoare-de-dragoste/

Înregistrările sunt redate prin YouTube; harta folosește OpenStreetMap; imaginile vin de la Wikimedia Commons, cu autorul și licența afișate; identificatorii din baze de date provin din Wikidata.

## Using this as a template for another book

The site is split in two:

| File | What it holds | Per book? |
|---|---|---|
| `index.html` | The page: layout, player, cinema, gallery, map, letter, print styles | Shared. Only the `<head>` lines marked “edit per book” change |
| `carte.js` | Everything about the book: texts, songs, films, references, photos, book club questions, and the **theme** | Yes: this is the file you replace |
| `og.png` | The 1200×630 image shown when the link is shared in chats | Yes, generated by `tools/og.html` |
| `tools/` | Research and checking helpers (not used by the site) | Shared |

The structure stays the same for every book: opening screen with the record player, the music named in the book, period songs, the cinema, the cultural references (gallery + map), the book club guide, and the sealed letter on first visit.

### Steps for a new book

1. **Copy the repository.** On GitHub, open this repository and choose **Use this template → Create a new repository** (one repository per book). In the new repository: **Settings → Pages → Deploy from a branch → `main` / root**. The site appears at `https://<user>.github.io/<repository>/`.
2. **Fill in `carte.js`.** Keep its shape; every field has a comment above it. Give the book a short new `id` (it keeps the “letter already seen” memory separate per book).
3. **Edit the `<head>` of `index.html`:** `<title>`, the description, the canonical and `og:url` addresses, `og:title`, `og:description`.
4. **Preview locally:** in the repository folder run `python3 -m http.server 8000` and open http://localhost:8000.
5. **Check every recording plays when embedded:** open http://localhost:8000/tools/verifica-youtube.html. Anything not marked “merge” needs another recording.
6. **Make the preview image:**
   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --window-size=1200,630 --virtual-time-budget=6000 --screenshot=og.png http://localhost:8000/tools/og.html
   ```
7. **Commit and push.** GitHub Pages publishes within a minute or two.

### The theme (`carte.js → theme`)

| Field | Effect |
|---|---|
| `colors.bg`, `panel` | Page background and raised surfaces |
| `colors.cream`, `muted` | Main text and secondary text. On a light theme, make `cream` dark |
| `colors.gold` (+ `gold-hi`, `gold-soft`, `gold-dim`, `gold-light`) | The accent: buttons, chips, links, ornaments, and its lighter/softer/dimmer/brightest shades |
| `colors.line`, `ink` | Hairlines; text drawn on the accent colour |
| `colors.seal`, `seal-hi` | Wax seal colour and its highlight |
| `colors.photo-text`, `photo-accent` | Text on gallery photos (always over a dark gradient: keep these light on a light theme) |
| `fonts.display`, `body`, `hand`, `href` | Headline, text and handwriting fonts, plus the Google Fonts address that loads them |
| `photo`, `photoBand`, `photoCard` | CSS filters that tone the opening photo, the section bands and the gallery cards (sepia, brightness…) |
| `ornament` | An SVG data URL for the small ornament before section titles (`null` = Art Deco fan). It is drawn in the accent colour |
| `grain`, `light`, `letter` | Film grain, the light that follows the mouse, the sealed letter on first visit (`true`/`false`) |

The cinema’s red curtains, the tickets, the vinyl record and the envelope keep their own colours in every theme; they are props.

### Research helpers

```bash
python3 tools/cauta.py ids ro:"Îngerul albastru" en:"City Lights"      # IMDb, Letterboxd, Cinemagia, Discogs… from Wikidata
python3 tools/cauta.py imagini ro:"Casa Capșa" en:"Tomb of Dante"      # free image + author + licence, ready to paste into refMeta
python3 tools/cauta.py capitole roman.txt "Capșa" "Fantasio|cinema"     # part and chapter where each term appears
```

### Rules the site follows (keep them for every book)

- Every song, film and place is checked in the book’s text, with the chapter where it appears.
- What the book names is kept apart from what we chose: `kind:'adaptation'` for songs, `ours:true` for films, and the notes say so.
- Only short quotes from the book, never long passages (the novels are usually still under copyright).
- Images are freely licensed; the author and licence are shown on every image.
- Recordings must play inside the page (checked with `tools/verifica-youtube.html`).
